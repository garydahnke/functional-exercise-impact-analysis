    (df["Exercise"] != "Pull Ups"),
    ["Date","Exercise","Sets","Reps","Weight","Workout Type"]

## 5. Best practices summary
- Use .copy() whenever you plan to modify a filtered subset.
- Skip .copy() if you're only reading values.
- Avoid chained assignment.
- Use type checks if unsure.

## Grounded takeaway
Without .copy(): may get a view, leading to warnings.
With .copy(): new DataFrame in memory, safe for modifications.
